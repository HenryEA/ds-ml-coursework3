Analysis of UK house prices and the FTSE 100 index, focusing on long-term price trends, returns, volatility, autocorrelation, and the comparison between property and equity market performance.

## Objectives

This code analyses UK house price and FTSE 100 data to:

* Analyse the long-term trend in UK average house prices
* Identify different phases in the UK housing market
* Calculate year-on-year house price growth
* Analyse monthly house price returns and autocorrelation
* Calculate CAGR over different periods
* Compare UK house price and FTSE 100 performance
* Calculate and compare annualized returns
* Calculate and compare volatility
* Discuss the differences between property and equity market performance
* Identify factors needed for a fair investment comparison

## Methods

The analysis uses Python and includes:

* Pandas
* NumPy
* Matplotlib
* Statsmodels
* Yahoo Finance data
* Moving average analysis
* Year-on-year growth analysis
* Monthly return calculation
* Autocorrelation analysis
* CAGR calculation
* Volatility analysis
* Financial time-series analysis
